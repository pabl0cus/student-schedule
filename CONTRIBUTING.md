# Contributing

Дякуємо за бажання допомогти незалежному студентському проєкту.

1. Створіть окрему гілку для однієї логічної зміни.
2. Не додавайте записи пар, бази даних, `.env`, паролі, токени, кеші моделей або персональні дані.
3. Збережіть сумісність із актуальним Docker Compose та задокументованими змінними середовища.
4. Перед pull request виконайте:

   ```bash
   npm run prettier
   npm run lint
   npm run build
   cd transcription_service && pytest
   ```

5. Опишіть мотивацію, поведінкові зміни та додайте скриншоти для помітних UI-правок.

Надсилаючи внесок, ви погоджуєтеся поширювати його за умовами [MPL-2.0](LICENSE). Матеріали третіх сторін
повинні мати сумісну ліцензію та чітке походження.
