# Студентський розклад

Я студент і зробив цей сайт, бо хотів мати розклад, записи пар і потрібні файли в одному місці — без зайвих
вкладок та пошуків у чатах.

[Відкрити сайт](https://schedule.kpi.lat)

Це незалежний проєкт. Він не пов’язаний з адміністрацією КПІ та не замінює офіційний
[розклад університету](https://schedule.kpi.ua).

## Що тут є

- розклад груп і викладачів за календарними тижнями;
- архів минулих тижнів;
- записи пар і звичайні вкладення;
- українська транскрипція з пошуком і переходом до таймкоду;
- окремий Windows-клієнт для волонтерської транскрибації.

## Як це працює

Актуальний розклад надходить з відкритого API КПІ. Записи та файли зберігаються на власному сервері. Перед
транскрибацією сервер готує окрему аудіодоріжку, а запрошений волонтерський комп’ютер обробляє її через Whisper
large-v3 і повертає текст із таймкодами.

Основні частини:

- `src/` — React, TypeScript і Vite;
- `transcription_service/` — FastAPI, SQLite, медіа та черга завдань;
- `community-transcriber-windows/` — Windows-клієнт для Whisper;
- `docker-compose.yml` — локальний запуск;
- `docker-compose.production.yml` — підключення до зовнішнього Caddy.

## Локальний запуск

Потрібен Docker:

```bash
cp .env.example .env
docker compose up -d --build
```

Сайт буде доступний на [http://127.0.0.1:3000](http://127.0.0.1:3000). GPU на сервері не потрібен.

Для роботи з frontend:

```bash
npm ci
npm run dev
```

Докладні налаштування backend є в
[transcription_service/README.md](transcription_service/README.md), а інструкція для волонтерського клієнта — в
[community-transcriber-windows/README.md](community-transcriber-windows/README.md).

## Важливо

Записи й транскрипції бачать користувачі, які відкрили матеріали відповідної пари. Додавайте лише те, що маєте
право поширювати. Волонтерський комп’ютер тимчасово отримує аудіодоріжку, тому доступ до черги варто давати лише
людям, яким ви довіряєте.

Секрети, база, медіафайли та локальні налаштування не зберігаються в Git.
